# mpv portable_config

## 저장 위치

이 저장소는 **`mpv.exe`가 있는 폴더 안에 `portable_config`라는 이름으로** 넣어야 합니다.
```
mpv.exe가 있는 폴더/portable_config
```
내 PC 경로: `여기에 실제 경로를 적기`  (예: `D:/Programs/mpv/portable_config`)
- 폴더 이름은 정확히 `portable_config`여야 합니다. 이름을 바꾸면 mpv가 인식하지 못합니다.
- 설치 후 mpv를 재시작해야 적용됩니다.

## 단축키
| 키 | 동작 |
|---|---|
| `SPACE` | 재생/일시정지 |
| `F` | 전체화면 |
| `Q` | 종료 |
| `←` / `→` | 5초 이동 |
| `Shift+←` / `Shift+→` | 30초 이동 |
| `0` ~ `9` (숫자패드 포함) | 전체 길이의 0% ~ 90% 위치로 이동 |
| `<` / `>` | 이전/다음 트랙 |
| `↑` / `↓` | 볼륨 ±5 |
| `M` | 음소거 |
| `A` | 오디오 트랙 변경 |
| `C` | 자막 표시/숨김 |
| `Shift+DEL` | 휴지통으로 삭제 |
| `/` | 단축키 메뉴 |
| `L` | 플레이리스트 |
| `H` | 단축키 도움말 |

### 숫자키 이동 예시

100초 영상 기준: `1` = 10초, `2` = 20초, ... `8` = 1분 20초, `9` = 1분 30초, `0` = 처음.
영상 길이에 비례해 이동하므로 다른 길이의 영상에서도 같은 비율로 동작합니다.
